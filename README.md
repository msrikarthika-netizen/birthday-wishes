# birthday-wishes

An interactive birthday-surprise website built with HTML, CSS, and JavaScript.

## Run locally

Open `index.html` in a browser, or serve this directory with any static-file server.

## Deploy on Netlify

This repository is ready to deploy as a static site—no build command is needed.

1. In Netlify, choose **Add new project** → **Import an existing project**.
2. Select the `msrikarthika-netizen/birthday-wishes` GitHub repository.
3. Leave the build command empty and set the publish directory to `.` (these are also defined in `netlify.toml`).
4. Click **Deploy site**.

Every push to `main` will trigger a new Netlify deploy after the repository is connected.
